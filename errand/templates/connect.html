Option 1: One command setup

Or configure a single client: errand connect cursor, claude-desktop, or vscode.

Python SDK Integration

No MCP required. Use directly with LangChain, LlamaIndex, OpenAI SDK, or custom agent loops:

from errand.client import Errand

errand = Errand(api_key="{{ demo_key or 'erk_YOUR_KEY' }}", base_url="{{ base_url }}")
receipt = errand.delegate(
    task="Write a Python function is_prime(n: int) -> bool",
    check="assert is_prime(17) and not is_prime(4)"
)
print("Answer:", receipt["answer"], "Verdict:", receipt["verdict"])
