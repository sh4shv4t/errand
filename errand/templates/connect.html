Option 1: one command

Detects the MCP clients on your machine and adds Errand to each one (backs up their config first).

errand connect all{% if not demo_key %} --key erk_YOUR_KEY{% endif %}

Or one client: errand connect cursor. Options: claude-desktop, claude-code, cursor, vscode, windsurf, gemini, codex. See everything with errand connect print.

Option 2: just a URL

Errand serves MCP over HTTP. Any client that supports remote MCP servers needs only this:

URL:    {{ base_url }}/mcp
Header: Authorization: Bearer {{ demo_key or 'erk_YOUR_KEY' }}

Client only accepts a URL? Use {{ base_url }}/mcp?key=... (keep that URL private).

No MCP? Use any framework

Python SDK, with tool schemas ready for OpenAI-style or Anthropic function calling:

from errand.client import Errand
e = Errand(api_key="{{ demo_key or 'erk_YOUR_KEY' }}", base_url="{{ base_url }}")
e.send_math("What is 17 * 23?")

tools = e.tools("openai")          # or "anthropic"
result = e.run_tool(name, args)    # execute the model's tool call

Schemas over HTTP: /v1/tools?format=openai · anthropic. Full agent example: examples/openai_agent.py (works with Ollama, OpenAI, Groq...).

Plain HTTP

curl -X POST {{ base_url }}/v1/errands \
  -H "Authorization: Bearer {{ demo_key or 'erk_YOUR_KEY' }}" \
  -H "Content-Type: application/json" \
  -d '{"lane":"math.final-answer","payload":{"problem":"What is 17 * 23?"}}'

Tools your agent gets

  • list_lanes, recommend_runner: what can be delegated, to whom, at what cost
  • send_errand: delegate and get a verified answer with a cost receipt
  • give_feedback, wallet
  • request_top_up: returns a PayPal link that a human approves
